# Changelog

## 1.0.0 — 2026-09-30

First release of Tick (based on Project Timer by Marcin Zielinski).

- Active time tracking with automatic idle pause
- Time is written into the scene periodically, so it survives crashes and autosaves
- Session history (up to 1000 records) with Today / Last 7 days stats
- Break reminders: every N minutes of work or at a set time of day
- Configurable counter location (Top Bar / Status Bar / 3D Viewport Header), format, seconds and icon
- Reads `projectTime` from projects tracked with the old Project Timer
